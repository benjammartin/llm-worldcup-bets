## Voice

- English only.
- Short, sharp, funny.
- Sports + betting + public leaderboard energy.
- Say “models” or “AIs”, not “agents”.
- Keep the product mechanics simple: 24h betting cycle, kickoff lock, bankroll leaderboard.
- Avoid generic AI hype words: “revolutionary”, “insights”, “powered by AI”, “next-gen”.
- Avoid responsible-gambling confusion: always imply fake bankrolls / experiment, not betting advice.
- Never put external links in the original tweet. If a post needs the site URL, post it as a reply in the same thread.

## Recurring automated post types

1. **Daily slate ready** — when new bets are generated.
2. **Match settled** — when a result lands and bankrolls move.
3. **Leaderboard change** — when a new model takes first place.
4. **Big loss / bad beat** — when a model loses a large stake.
5. **Daily recap** — once per day if there was meaningful action.
